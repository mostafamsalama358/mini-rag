# Exception ADR Template

Use only when waiving a Principle, Invariant, or Forbidden Pattern for a **bounded** case.

```markdown
### ADR-XXX — <Title>

- **Context**: <real architectural problem>
- **Decision**: <selected option, including which rule is waived>
- **Alternatives considered**: (A) … (B) … (C) …
- **Tradeoffs**: <honest costs>
- **Scope**: <what is covered / not covered>
- **Duration**: <time box or phase bound>
- **Exit criteria**: <what must be true to end the exception>
```

Standing philosophy belongs in Principles — do not create ADRs that only restate P/I rules.
