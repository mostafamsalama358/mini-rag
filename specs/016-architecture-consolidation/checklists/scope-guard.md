# Scope Guard (016)

Consolidation acceptance MUST NOT require:

- [ ] Performance optimization program
- [ ] Retrieval/ranking algorithm redesign
- [ ] Model evaluation methodology redesign (beyond using existing offline gate)
- [ ] External API redesign
- [ ] Database redesign unrelated to ownership
- [ ] New product feature development
- [ ] Implementation task lists embedded back into `spec.md` / `plan.md` as coding prescriptions
- [ ] Package-winner selection by age/folder name (AP12)

If any box above was needed for “done”, stop — that work belongs in a different spec.
