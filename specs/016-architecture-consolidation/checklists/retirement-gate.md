# Retirement Gate Checklist

Use before removing a Retire After Cutover competitor.

- [ ] Sole Active Production Owner exists for the concern (`ownership-registry.md`)
- [ ] Zero production consumers of the retiree (documented scan/review)
- [ ] Rollback drill completed (`governance/rollback-drill.md`)
- [ ] Transitional diagnostics cannot remain as hidden path (lifecycle updated)
- [ ] Predecessor sole-owner phase complete per `migration-runbook.md`
- [ ] Architecture-review checklist attached if exception needed
