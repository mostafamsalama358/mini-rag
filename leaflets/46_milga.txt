6. Interactions (from NEW DRUG INTERACTION.xlsx)
- Vitamin B6 (Pyridoxine) + THIOPENTAL: Risk: High-dose pyridoxine (>200mg/day) induces metabolism → reduced thiopental efficacy → inadequate anesthesia/sedation. Monitoring: EEG during anesthesia; serum thiopental levels if prolonged use. Dosage: Increase thiopental dose 20-30% for induction. Patient Warning: Disclose all supplements pre-surgery; report in…
- Vitamin B6 (Pyridoxine) + PHENOBARBITAL: Risk: Pyridoxine (>200mg/day) accelerates phenobarbital metabolism → subtherapeutic levels → breakthrough seizures. Monitoring: Serum phenobarbital levels (target 15-40 μg/mL) q2wk. Dosage: Increase phenobarbital 20-50% if levels drop. Patient Warning: Report aura/seizure recurrence; never stop antiepileptic suddenly.
- Vitamin B6 (Pyridoxine) + PHENOBARBITONE: Risk: Pyridoxine (>200mg/day) accelerates phenobarbital metabolism → subtherapeutic levels → breakthrough seizures. Monitoring: Serum phenobarbital levels (target 15-40 μg/mL) q2wk. Dosage: Increase phenobarbital 20-50% if levels drop. Patient Warning: Report aura/seizure recurrence; never stop antiepileptic suddenly.
- Vitamin B6 (Pyridoxine) + PRIMIDONE: Risk: Pyridoxine induces metabolism → reduced primidone/phenobarbital levels → loss of seizure control. Monitoring: Serum primidone (5-12 μg/mL) and phenobarbital levels monthly. Dosage: Increase primidone 25-50mg/day increments. Patient Warning: Report dizziness/ataxia with dose increases; avoid >100mg/day B6.
- Vitamin B6 (Pyridoxine) + AMOBARBITAL: Risk: Reduced amobarbital efficacy → sedation/anesthesia failure. Monitoring: Respiratory rate and sedation scores during use. Dosage: Increase amobarbital 30-50% for procedural sedation. Patient Warning: Disclose B6 use before medical procedures.
- Vitamin B6 (Pyridoxine) + PENTOBARBITAL: Risk: Pyridoxine-induced clearance → inadequate coma induction in refractory status epilepticus. Monitoring: Continuous EEG in ICU settings. Dosage: Higher pentobarbital loading doses (5-10mg/kg). Patient Warning: N/A (critical care use only).
- Vitamin B6 (Pyridoxine) + SECOBARBITAL: Risk: Diminished secobarbital effect → insomnia treatment failure. Monitoring: Sleep architecture studies if available. Dosage: Avoid chronic use; consider non-barbiturate hypnotics. Patient Warning: Report rebound insomnia; max B6 ≤100mg/day.
- Vitamin B6 (Pyridoxine) + PHENYTOIN: Risk: Reduced phenytoin efficacy → breakthrough seizures (pyridoxine >200mg/day induces metabolism). Monitoring: Serum phenytoin levels (target 10-20 μg/mL) monthly. Dosage: Avoid high-dose B6; if essential, increase phenytoin by 25-50 mg/day. Patient: Report aura/seizure recurrence immediately.
- Vitamin B6 (Pyridoxine) + LEVODOPA: Risk: Pyridoxine cofactor effect → peripheral decarboxylation → ↓ levodopa CNS bioavailability → Parkinsonism exacerbation; Monitoring: "ON" time duration; Dosage: Avoid unless with decarboxylase inhibitor (carbidopa/benserazide); if essential, ↑ levodopa by 100-200mg/day; Patient: Do not take B6 supplements without c…
- Vitamin B12 (Cyanocobalamin) + CHLORAMPHENICOL: Risk: CHLORAMPHENICOL may antagonize VITAMIN B12's hematinic effects, potentially masking/mimicking B12 deficiency. Monitoring: Weekly FBC, serum B12 levels (especially with prolonged therapy >2 weeks). Dosage: No adjustment needed. Patient Warning: Report fatigue/pallor; B12 supplementation may need continuation post…
- Vitamin B12 (Cyanocobalamin) + COLCHICINE: Risk: Colchicine impairs B12 absorption, potentially worsening deficiency. Monitoring: B12 levels annually if chronic use. Dosage: No adjustment. Patient Warnings: Separate doses by ≥2hr; monitor for paresthesia.
- Vitamin B12 (Cyanocobalamin) + METFORMIN: Risk: Metformin reduces B12 absorption (incidence: 5-30%), risking neuropathy. Monitoring: B12/MMA every 1-2yr. Dosage: B12 supplementation may be needed. Patient Warnings: Separate doses by ≥2hr; calcium may counteract effect.
Also avoid duplicating the same actives in other cold/pain/antibiotic products.
