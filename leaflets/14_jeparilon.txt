6. Interactions (from NEW DRUG INTERACTION.xlsx)
- Famotidine + AMIODARONE: Risk: Minimal interaction (safe alternative); Type: None; Monitoring: Routine care; Dosage Adjustments: None needed; Alternative: Pantoprazole; Patient Warnings/Management: None specific.
- Famotidine + TOLAZOLINE: Risk: Minimal interaction expected; Type: Pharmacodynamic; Monitoring: Standard tolazoline monitoring; Dosage Adjustments: None typically; Alternative: Pantoprazole if concerned; Patient Warnings/Management: No special precautions.
- Famotidine + DIPYRIDAMOLE: Risk: Mild absorption delay (pH effect). Type: Pharmacokinetic. Monitoring: Headache timing (therapeutic marker). Dosage Adjustments: MR formulation preferred. Alternative: Rabeprazole. Patient Warnings/Management: Evening H2A dosing minimizes interaction.
- Famotidine + VERAPAMIL: Risk: Mild PR prolongation (additive AV node effects); Type: Pharmacodynamic; Monitoring: ECG PR interval weekly; Dosage Adjustments: Verapamil ↓25% if HR<55 bpm; Alternative: Pantoprazole; Patient Warnings/Management: Report dizziness/syncope.
- Famotidine + NIFEDIPINE: Risk: Reflex tachycardia (acute); Type: Pharmacodynamic; Monitoring: BP/HR q4h x3 doses; Dosage Adjustments: Nifedipine XL formulation; Alternative: Nifedipine + sucralfate; Patient Warnings/Management: Seated BP measurements.
- Famotidine + DILTIAZEM: Risk: Bradycardia exacerbation; Type: Pharmacodynamic; Monitoring: Ambulatory HR for 24h; Dosage Adjustments: Diltiazem CD formulation preferred; Alternative: Diltiazem + antacids; Patient Warnings/Management: Nighttime HR checks.
- Famotidine + NICARDIPINE: Risk: Enhanced cerebral vasodilation; Type: Pharmacodynamic; Monitoring: Neurological checks q2h; Dosage Adjustments: Nicardipine ↓0.5mg/kg/min; Alternative: IV pantoprazole; Patient Warnings/Management: Headache reporting.
- Famotidine + AMLODIPINE: Risk: Delayed edema onset (2-3 weeks); Type: Pharmacodynamic; Monitoring: Ankle circumference weekly; Dosage Adjustments: Amlodipine ↓2.5mg if edema; Alternative: Amlodipine + PPIs; Patient Warnings/Management: Leg elevation protocol.
- Famotidine + NISOLDIPINE: Risk: Photosensitivity exacerbation; Type: Pharmacodynamic; Monitoring: Skin exam q2weeks; Dosage Adjustments: Nisoldipine ↓10mg if rash; Alternative: Nisoldipine + magaldrate; Patient Warnings/Management: SPF 50+ required.
- Famotidine + FELODIPINE: Risk: CYP3A4 substrate competition; Type: Pharmacokinetic; Monitoring: BP q12h; Dosage Adjustments: Felodipine ↓25%; Alternative: Felodipine + aluminum hydroxide; Patient Warnings/Management: Grapefruit strict avoidance.
- Famotidine + BEPRIDIL: Risk: QT prolongation (additive K+ effects); Type: Pharmacodynamic; Monitoring: Telemetry, QTc q8h; Dosage Adjustments: Absolute contraindication; Alternative: Famotidine + verapamil; Patient Warnings/Management: Defibrillator access required.
- Famotidine + ISRADIPINE: Risk: Cerebral hypoperfusion; Type: Pharmacodynamic; Monitoring: ICP if available; Dosage Adjustments: Famotidine hold during infusion; Alternative: IV PPIs; Patient Warnings/Management: Neuro checks q1h.
Also avoid duplicating the same actives in other cold/pain/antibiotic products.
