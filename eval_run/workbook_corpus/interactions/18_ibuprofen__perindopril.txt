Brand: Brufen
API 1: IBUPROFEN
API 2: PERINDOPRIL
Risk: Moderate BP increase (+10-15 mmHg) and reversible renal dysfunction
Type: Pharmacodynamic
Monitoring: BP pre/post dose, Cr if use >3 days
